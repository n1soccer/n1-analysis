# N1 プレー分析ボード（自分専用アプリ）

試合・練習の動画に、矢印・選手マーク・分身・視野・スポットライト・コメント・一時停止を書き込み、
書き込み入りの動画として書き出せるアプリ。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | アプリ本体（画面・機能すべて） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン |
| `sw.js` | オフラインで使えるようにする仕組み |
| `icons/` | アプリのアイコン |

## 公開のしかた（GitHub Pages・無料）

1. GitHub で新しいリポジトリ `n1-analysis` を作る
2. このフォルダの中身をすべてアップロード（`icons` フォルダごと）
3. リポジトリの Settings → Pages → Branch を `main` / `/(root)` にして Save
4. 1〜2分後に `https://（ユーザー名）.github.io/n1-analysis/` で開ける
5. iPhone / iPad は Safari で開いて「共有 → ホーム画面に追加」、パソコンの Chrome はアドレスバー右の「インストール」

## 編集するとき

- Claude にこのリポジトリをつないで「◯◯を直して」と頼む → 修正してリポジトリに反映される
- 反映後、アプリを開き直すと新しいバージョンになる（ネットにつながっているとき）
- 自分で直す場合は `index.html` を編集し、`sw.js` の `VERSION` の数字を1つ上げる

## データについて

- 動画はどこにも送られない。端末の中だけで再生・書き出しする
- 書き込んだ内容は、その端末のアプリの中に動画ごとに自動保存される
- 別の端末に移すときは「データの書き出し・読み込み」の「JSONをコピー」を使う
