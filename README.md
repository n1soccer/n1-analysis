# N1 プレー分析ボード（N1分析）

試合・練習の動画に矢印・選手マーク・エリア・コメントを書き込み、フリーズやカットを入れて、分析動画として書き出せるアプリ。
ブラウザで動き、動画はどこにも送られません（端末の中だけで再生・書き出し）。

- アドレス：`https://n1soccer.github.io/n1-analysis/`
- iPhone / iPad：Safari で開いて「共有 → ホーム画面に追加」で、アプリのように全画面で使える

## できること

| 機能 | 内容 |
| --- | --- |
| 書き込み | パス・ラン・スペース・選手マーク・スポットライト・ライト・発光・ZOOM・強調・視野・つなぐ・分身・三角・四角・フリー・文字 |
| ライト | 選手に上から光の柱が当たる。自動で追いかけられる |
| 発光 | 四角で囲んだ選手の形にそって色が光る。自動で追いかけられる |
| ZOOM | 円の中を拡大（1.5 / 2 / 3倍）。自動で追いかけられる |
| 自動追跡 | 選手マーク・ライト・発光・ZOOM が選手を追いかける。動きの予測と見た目の照合で、似た選手が隣にいても乗り移りにくく、一瞬隠れても続ける。ずれたら「ここから追いかけ直す」 |
| 選手を前に | 芝の色を見分けて、矢印やエリアが選手の後ろを通るように見せる（白線は消さない） |
| 選手の名前 | 選手マークに名前・背番号を付ける。自動追従と一緒に動く |
| 登場アニメ | 図形はパッと光って現れ、矢印はスッと伸びる |
| タイムライン | 図形・文字・コメントの表示期間をバーで調整。動画のサムネイル列で分割・削除（カット） |
| 複製 | 選んだ動画の部分をすぐ後ろにもう一度入れる。部分ごとに「図形：あり／なし」「フリーズ：あり／なし」を選べる。「素の映像で複製」で何も手を加えていない映像をそのまま入れられる |
| フリーズ | 今の位置に3秒の静止を入れる。両端を引いて長さを変更 |
| 書き出し | 720p / 1080p を選んで MP4 で書き出し。音声の有無も選べる |
| 元に戻す / やり直す | Ctrl/⌘+Z、Ctrl/⌘+Shift+Z |

### キー操作（パソコン）

| キー | 動作 |
| --- | --- |
| Space | 再生 / 一時停止 |
| ← / → | 1コマ戻る / 進む（Shift で1秒） |
| F | 今の位置にフリーズを入れる |
| N | 次の場面へ |
| Ctrl/⌘ + Z | 元に戻す |
| Ctrl/⌘ + Shift + Z、Ctrl + Y | やり直す |

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の部品 |
| `css/app.css` | 見た目 |
| `js/app.js` | 動き（すべての機能） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン |
| `sw.js` | オフラインで使えるようにする仕組み |
| `icons/` | アプリのアイコン |
| `board/` | N1 フォーメーションボード（別アプリ） |
| `classic/` | 機能を増やす前の分析アプリ（2026年11月までの版・予備） |

## 更新するとき

- `index.html` の `css/app.css?v=` と `js/app.js?v=` の数字、`sw.js` の `VERSION` と `SHELL` の `?v=` を1つ上げる
- 反映後、アプリを開き直すと新しいバージョンになる（ネットにつながっているとき）

## データについて

- 書き込んだ内容は、その端末のアプリの中に動画ごとに自動保存される
- 別の端末に移すときは「作業をファイルに保存」→ 移した先で「作業ファイルを開く」
